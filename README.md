The aim of this project is to write small Python programs that:
1.	Convert MW to kW.
2.	Calculate energy from power and time.
3.	Calculate percentage change.
4.	Calculate a weighted average.
5.	Convert a list of half-hourly MW values into MWh.
6.	Calculate the carbon emissions associated with a given electricity consumption.

These programs will form the foundations of analysing more complex electricity and carbon emissions data to answer key energy industry questions.
